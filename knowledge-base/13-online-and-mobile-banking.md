# Online and Mobile Banking

## Features
With the Nova Bank app, customers can check balances and transactions, transfer money, pay bills, block and unblock cards temporarily, order replacement cards, set up alerts, upload identity documents, and send secure messages.

## Logging in
Customers log in with their username and password, plus a one-time passcode sent to their phone. Nova Bank will never ask for this passcode on a call.

## Forgotten password
Customers can reset their password in the app by tapping Forgot Password and verifying with a code sent to their registered phone number.

## New phone
When a customer gets a new phone, they need to download the app again and log in. A verification code is sent to their registered phone number. If the phone number has changed, the customer must visit a branch or create a support ticket for a human agent to update it securely.

## Locked out
After 5 wrong password attempts, the app locks for 30 minutes. If the customer is still locked out after that, they should reset their password or create a support ticket.

## App problems
If the app is not working, customers should update it to the latest version and restart their phone. If the problem continues, a support ticket should be created with a description of the problem.
